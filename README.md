# Devman Telegram Bot

Telegram-бот для автоматического получения уведомлений о проверке учебных работ на [Девмане](https://dvmn.org/).

Бот использует Long Polling API Девмана для отслеживания проверок и отправляет уведомления в Telegram.

## Возможности

- Отслеживание проверок работ через Long Polling API.
- Отправка уведомлений в Telegram.
- Отображение названия проверенной работы.
- Уведомление о результате проверки: работа принята или возвращена на доработку.
- Обработка ошибок соединения и превышения времени ожидания.

## Требования

- Python 3.12
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather)
- API-токен Девмана

## Установка

**1. Создайте виртуальное окружение:**

```bash
python -m venv .venv
```

**2. Активируйте окружение:**

Windows:

```bash
.venv\Scripts\activate
```

**3. Установите зависимости:**

```bash
pip install -r requirements.txt
```

## Настройка

Создайте файл `.env` в корневой директории проекта:

```env
TOKEN=ваш_токен_девмана
TG_TOKEN=ваш_токен_telegram_бота
CHAT_ID=ваш_chat_id
```

Где:

- `TOKEN` — API-токен, полученный на [Девмане](https://dvmn.org/api/docs/).
- `TG_TOKEN` — токен Telegram-бота от [@BotFather](https://t.me/BotFather).
- `CHAT_ID` — идентификатор вашего Telegram-чата. Его можно узнать через [@userinfobot](https://t.me/userinfobot).

Перед запуском откройте своего Telegram-бота и нажмите **Start**.

**Важно:** не публикуйте файл `.env` и не передавайте свои API-токены другим пользователям.

## Запуск

Запустите скрипт:

```bash
python main.py
```

Бот начнёт отслеживать новые проверки работ.

Когда преподаватель проверит работу, бот отправит уведомление в Telegram.

**Пример сообщения:**

```text
У вас проверили работу "Отправляем уведомления о проверке работ"
Преподавателю все понравилось, можно приступать к следующему уроку!
```

Или:

```text
У вас проверили работу "Отправляем уведомления о проверке работ"
К сожалению, в работе нашлись ошибки.
```

## Как это работает

1. Программа отправляет запрос к Long Polling API Девмана.
2. Сервер ожидает появления новых проверок.
3. При получении проверки программа определяет её название и результат.
4. Telegram-бот отправляет пользователю уведомление.
5. Программа продолжает отслеживание проверок.

При потере соединения или превышении времени ожидания программа повторяет запрос.
